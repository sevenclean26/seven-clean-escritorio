# Seven Clean · Programa para Windows

Instaladores del programa de escritorio de **Seven Clean**, sistema de ventas e inventario.
Aquí solo están las versiones publicadas; este repositorio no tiene código.

## Instalar

1. Abre la [última versión](https://github.com/sevenclean26/seven-clean-escritorio/releases/latest) y descarga
   `SevenClean_<versión>_x64-setup.exe`.
2. Ábrelo. Si Windows muestra «Windows protegió su PC», elige «Más información» → «Ejecutar de todas formas».
3. El programa queda en el menú Inicio y en el Escritorio como «Seven Clean».

## Actualizaciones

El programa se actualiza solo: al abrirlo, si hay una versión nueva, muestra «Actualizando Seven Clean…», la instala
y se vuelve a abrir.
